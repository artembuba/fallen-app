# FALLEN — Discipline over everything (v2)

## Возможности
- План тренировок на 7 дней: дни, фокус и упражнения.
- Упражнения с рабочим весом, подходами и повторениями.
- Отметка тренировок, история и редактирование записей.
- Streak с учётом запланированных тренировочных дней (дни отдыха не обрывают серию).
- Календарь активности и график условного тренировочного объёма.
- Персональные задачи по датам и категориям.
- Таймер отдыха: 60 / 90 / 120 / 180 секунд.
- Уровни дисциплины и XP за тренировки и выполненные задачи.
- Кодекс с принципами стоицизма и разумной дисциплины.
- Локальное хранение и экспорт JSON-резервной копии.

## Открытие локально
Распакуйте архив и откройте `index.html` в браузере. Основные функции доступны без сети, данные хранятся в localStorage браузера.

## Установка как PWA на Android / iPhone
PWA — это устанавливаемое веб-приложение, не публикация в App Store или Google Play.
1. Разместите содержимое папки на HTTPS-хостинге (например, GitHub Pages или Netlify).
2. Откройте сайт онлайн один раз, чтобы браузер загрузил файлы и Service Worker сохранил их для офлайн-работы.
3. Android/Chrome: меню браузера → «Установить приложение» или «Добавить на главный экран».
4. iPhone/iPad/Safari: кнопка «Поделиться» → «На экран Домой».
5. Запустите с иконки. После первого успешного кэширования интерфейс открывается без интернета.

## Данные
Тренировки и задачи хранятся локально в браузере на устройстве. Они не синхронизируются автоматически между устройствами. Используйте кнопку «Экспорт» для создания резервной копии JSON. Не очищайте данные сайта, если хотите сохранить историю.

## Важно
Открытие `index.html` через `file://` позволяет работать локально, но PWA-установка и Service Worker требуют HTTPS или localhost. Для публикации в магазинах приложений потребуется отдельная упаковка и соблюдение правил магазинов.
